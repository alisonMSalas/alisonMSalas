**CiAuto · Pasantía &nbsp;`privado`**

### CiAuto Automation System
**CiAuto · Pasantía &nbsp;`privado`**

Plataforma de automatización de procesos financieros y operativos para una empresa automotriz: Cuentas por Cobrar con aging de cartera, Riesgo de Clientes con matriz configurable, catálogo de vehículos con importación XML/Excel y procesamiento de estados bancarios. Reportes Excel (Apache POI) y PDF (iText7). Flujos n8n para envío masivo de emails y clasificación de transacciones.
